## 📖 简介

FastScan 是一款专为**内存分析**和**基址定位**设计的 Android 工具。通过 WebSocket 连接服务端，提供基址搜索、对比、过滤等功能，帮助用户快速定位目标内存地址。

### ✨ 核心功能

- 🔍 **基址搜索** - 在内存中搜索目标地址
- 📊 **基址对比** - 对比多个文件，筛选有效地址
- 🎯 **基址过滤** - 精确过滤，缩小地址范围
- 🔗 **指针调试** - 批量调试指针链，验证地址有效性

---

## 🔍 基址搜索

在内存中搜索目标地址，支持多种配置选项。

### 功能特点

- ✅ 支持 32位/64位 进程
- ✅ 可配置扫描层级（1-100）
- ✅ 可设置扫描范围
- ✅ 支持快速/普通扫描模式
- ✅ 支持多核并行扫描
- ✅ 支持模块扩展和负偏移

### 使用步骤

```
1️⃣  输入目标地址（十六进制）
    ↓
2️⃣  选择进程位数（32/64）
    ↓
3️⃣  设置扫描参数
    ↓
4️⃣  选择模块文件
    ↓
5️⃣  点击"开始搜索"
    ↓
6️⃣  等待扫描完成
```

### 配置参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 扫描层级 | 指针追踪深度 | 6 |
| 扫描范围 | 内存区域大小 | 0x7D0 |
| 扫描核心 | 并行线程数 | 8 |
| 快速模式 | 加速扫描 | 关闭 |
| 读取受限 | 访问受限内存 | 关闭 |

## 📊 基址对比

对比多个文件，筛选出有效的内存地址。

### 功能特点

- ✅ 支持基础对比、极速对比、单线程对比
- ✅ 基础对比支持 2 个文件
- ✅ 极速/单线程对比支持 8 个文件
- ✅ 可设置层级限制和最大数量
- ✅ 支持索引检查和 NOP 优化

### 对比模式

| 模式 | 文件数 | 速度 | 适用场景 |
|------|--------|------|----------|
| 基础对比 | 2 | 普通 | 精确对比 |
| 极速对比 | 8 | 快速 | 大量文件 |
| 单线程对比 | 8 | 普通 | 稳定性优先 |

### 使用步骤

```
1️⃣  选择对比模式
    ↓
2️⃣  选择要对比的文件
    ↓
3️⃣  设置对比参数
    ↓
4️⃣  点击"开始对比"
    ↓
5️⃣  查看对比结果
```

## ⚙️ 基础配置

配置进程和内存范围等基础参数。

### 功能特点

- ✅ 自动获取进程列表
- ✅ 支持手动输入 PID
- ✅ 可配置内存范围（Java/C堆、栈、代码段等）
- ✅ 支持进程监控和重启提示

### 内存范围说明

| 范围 | 代码 | 说明 |
|------|------|------|
| Java_heap | Jh | Java 堆 |
| C_heap | Ch | C++ 堆 |
| C_alloc | Ca | C++ 分配区 |
| C_data | Cd | C++ .data 段 |
| C_bss | Cb | C++ .bss 段 |
| Anonymous | A | 匿名内存 |
| Stack | S | 栈内存 |
| Code_app | Xa | 应用代码段 |
| Code_exec | Xe | 可执行代码段 |

### 使用步骤

```
1️⃣  选择目标进程
    ↓
2️⃣  或手动输入 PID
    ↓
3️⃣  勾选需要的内存范围
    ↓
4️⃣  保存配置
```

## 🔗 指针调试

批量调试指针链，验证地址有效性。

### 功能特点

- ✅ 支持批量调试（最多 200 条）
- ✅ 自动追踪指针链
- ✅ 显示每一步的地址和值
- ✅ 支持 DWord 和 Float 显示

### 输入格式

```
基址 + 偏移1 + 偏移2 + ...
```

### 示例

```
0x12345678 + 0x10 + 0x20 + 0x8
0xABCD1234 + 0x100
0x1000 + 0x20 + 0x40 + 0x80
```

### 调试结果

```
输入: 0x12345678 + 0x10 + 0x20 + 0x8
  ↓
0x12345678
  ↓ +0x10
0x12345688
  ↓ +0x20
0x123456A8
  ↓ +0x8
0x123456B0  ← 最终地址
DWord: 12345
Float: 3.14159
```

## ❓ 常见问题

### 🔴 无法连接服务器？

**检查项目：**
- 服务端程序是否启动
- 服务器地址是否正确
- 网络连接是否正常
- 防火墙是否放行

**解决方法：**
```bash
# 检查服务端是否运行
ps aux | grep fscan

# 检查端口是否监听
netstat -tlnp | grep 8080
```

---

### 🟡 扫描不到数据？

**可能原因：**
- 未授予 Root 权限
- 进程选择错误
- 内存范围未勾选
- 扫描参数配置不当

**解决方法：**
```bash
# 检查 Root 权限
su -c "id"

# 重新选择进程
# 勾选更多内存范围
# 调整扫描层级和范围
```

---

### 🟢 扫描速度慢？

**优化建议：**
- ✅ 减少扫描层级
- ✅ 缩小扫描范围
- ✅ 使用快速模式
- ✅ 减少扫描核心数

---

### 🔵 指针调试失败？

**检查项目：**
- 基址是否正确
- 偏移量是否有效
- 进程是否存活
- 内存是否可访问

**解决方法：**
- 重新确认基址
- 检查偏移量格式
- 刷新进程列表
- 尝试其他内存范围
